  [Telegram-команда] ──→ telegram-bot/index.js

                    │  agents/scout/index.js  │
                    │  Promise.allSettled([   │
                    │    perplexity(topics),  │

                    │    firecrawl(topics)    │
                    │  ])                     │
                    └───────────┬────────────┘
                                │
                    ┌───────────▼────────────┐
                    │  scoutResult =          │
                    │  {                      │
                    │    data: {              │
                    │      perplexity:        │

                    │        [{title,url,     │

                    │    tools_used: [...]    │
                    │    errors: [...]        │
                    │    cost_usd: 0.025      │
                    │  }                      │
                    └───────────┬────────────┘
                                │
                    ┌───────────▼────────────┐
                    │  LLM → Telegram-текст  │
                    │  claude-haiku /        │
                    │  claude-sonnet (deep)  │
                    └───────────┬────────────┘
                                │
                    ┌───────────▼────────────┐
                    │  buildStructuredResult  │
                    │  {raw: {perplexity,     │
                    │         youtube,        │
                    │         firecrawl}}     │
                    │                         │
                    │  buildConfidence        │
                    │  {level: высокая/средн/ │
                    │          низкая,        │
                    │   explanation: "..."}   │
                    └─────────┬───────────────┘

              ┌───────────────┴───────────────┐

  ┌───────────────────────┐    ┌──────────────────────────────────┐

  │    job_id,            │    │    job_id,                       │

  │    result: {raw},     │    │    query_topics,                 │

  │    status,            │    │    result: {raw},                │
  │    report,  ←──────── │ ── │── telegram_text: report,        │
  │    meta               │    │    confidence, meta              │
  │  }                    │    │  })  [fire-and-forget]           │
  └────────┬──────────────┘    └──────────────────────────────────┘
           │

  telegram-bot → ctx.reply(result.report)

## ПРАВИЛА МАРШРУТИЗАЦИИ (Алгоритм работы)

```
╔══════════════════════════════════════════════════════════════════╗
║  AGENT 1 — ЧТО ДЕЛАЕТ САМ / ЧТО ПЕРЕДАЁТ АГЕНТУ 2              ║
╚══════════════════════════════════════════════════════════════════╝

  Запрос                             Обработчик
  ─────────────────────────────────────────────────────────────────
  Факты, тренды, бизнес-запрос  ───→ Perplexity sonar (сам)
  Deepresearch-режим            ───→ Perplexity sonar-pro (сам)
  Метаданные YouTube-видео      ───→ Apify youtube-scraper (сам)
  Текстовые статьи / сайты      ───→ Firecrawl search (сам)
  OSINT (username/domain/ip...) ───→ Perplexity + Firecrawl (сам)
  Готовые субтитры YouTube      ───→ youtube-transcript-api (сам)
  ─────────────────────────────────────────────────────────────────
  Транскрибация видео/аудио     ───→ ПЕРЕДАТЬ Агенту 2 (ссылку)
  Глубокий JS-парсинг сайта     ───→ ПЕРЕДАТЬ Агенту 2 (URL)
  Разбор PDF / документов       ───→ ПЕРЕДАТЬ Агенту 2 (файл)
  Vision-анализ изображений     ───→ ПЕРЕДАТЬ Агенту 2
  Визуал + аудио видео          ───→ ПЕРЕДАТЬ Агенту 2
```

## ДВОЙНОЙ ВЫВОД — КЛЮЧЕВОЙ ПРИНЦИП

```
  ┌─────────────────────────────────────────────────────────────┐
  │  Каждый запрос Агента 1 производит два результата:          │
  │                                                             │
  │  1. TELEGRAM-ТЕКСТ (для пользователя)                       │
  │     • Форматированный Markdown                              │
  │     • Эмодзи, блоки ━━━, *жирный* текст                    │
  │     • Секции: 🔥 Тренды / 📱 Платформы / 💡 Идеи / ⚠️      │
  │     • Добавляется строка затрат                             │
  │                                                             │
  │  2. СТРУКТУРИРОВАННЫЙ JSON (для Агента 3)                   │
  │     • Сохраняется в intelligence_agent.search_results       │
  │     • job_id (UUID) — идентификатор поиска                 │
  │     • source_type: 'search'                                  │
  │     • result.raw.perplexity — весь summary + citations      │
  │     • result.raw.youtube — массив видео с метриками         │
  │     • result.raw.firecrawl — массив статей с контентом      │
  │     • confidence.level — высокая / средняя / низкая         │
  │     • meta — время, стоимость, инструменты, ошибки          │
  └─────────────────────────────────────────────────────────────┘
```

## СХЕМА SUPABASE: ТАБЛИЦЫ АГЕНТА 1

```
  Схема: intelligence_agent
  ─────────────────────────────────────────────────────────────────

  users
    telegram_id BIGINT PK
    settings    JSONB      ← темы, платформы, depth, время запуска

  search_results
    id           BIGSERIAL PK
    job_id       UUID       ← связь с result.job_id из оркестратора
    telegram_id  BIGINT     ← чей поиск
    task_type    TEXT       ← 'report' | 'trends' | 'search'
    query_topics TEXT[]     ← список тем запроса
    depth        TEXT       ← 'quick' | 'standard' | 'deep'
    status       TEXT       ← 'ok' | 'partial' | 'error'
    result       JSONB      ← {raw: {perplexity, youtube, firecrawl}}
    telegram_text TEXT      ← копия Telegram-отчёта (fallback)
    confidence   JSONB      ← {level, explanation}
    meta         JSONB      ← {tools_used, cost_usd, duration_sec...}
    created_at   TIMESTAMPTZ

  reports       ← история финальных отчётов (v1.5)
  api_costs     ← детализация расходов по каждому вызову
```
