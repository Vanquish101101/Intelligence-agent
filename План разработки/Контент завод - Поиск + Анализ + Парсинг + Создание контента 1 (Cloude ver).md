### ВИДЕО (главный приоритет)

#### Источники и получение

| Инструмент | Что делает | Стоимость |
|---|---|---|
| **yt-dlp** | Скачивает видео/аудио с YouTube, Vimeo, TikTok, Instagram, 1000+ сайтов | Бесплатно |
| **youtube-transcript-api** | Вытаскивает субтитры YouTube без скачивания видео | Бесплатно |
| **Playwright / Puppeteer** | Скрапит страницы с встроенным видео, JS-сайты | Бесплатно |
| **Apify** | Готовые акторы для YouTube, TikTok, Instagram, LinkedIn | $5+/мес |

**Лайфхак:** у большинства YouTube-видео уже есть автосубтитры Google — вытаскиваются за секунды и бесплатно через `youtube-transcript-api`. Это самый дешёвый вариант для речи.

```python
from youtube_transcript_api import YouTubeTranscriptApi
transcript = YouTubeTranscriptApi.get_transcript("VIDEO_ID", languages=["ru", "en"])
```

#### Извлечение аудио и кадров из локального файла

```bash
ffmpeg -i video.mp4 -vn -ar 16000 audio.wav          # аудио
ffmpeg -i video.mp4 -vf fps=0.5 frame_%04d.jpg        # кадр каждые 2 сек
```

#### Понимание видео — ключевой вопрос

**Сценарий:** в видео объяснение сопровождается визуальным рядом без слов — схемы, код на экране, анимация, демо. Нужно понять и слова, и картинку, и связь между ними.

**Решение — Google Gemini (единственная модель, принимающая видео целиком):**

| Модель | Контекст | Цена | Что умеет |
|---|---|---|---|
| **Gemini 1.5 Flash** | до 1 часа видео | $0.00035/1K токенов | аудио + визуал одновременно |
| **Gemini 2.0 Flash** | до 1 часа | дешевле Pro | умнее, быстрее |
| **Gemini 1.5 Pro** | до 2 часов | $0.00125/1K токенов | максимальная точность |

Gemini понимает одновременно: что говорится в аудио + что показывается на экране + контекстную связь между ними. Может описать немой фрагмент и объяснить его смысл в контексте речи.

```python
import google.generativeai as genai

model = genai.GenerativeModel("gemini-2.0-flash")
video = genai.upload_file("video.mp4", mime_type="video/mp4")

response = model.generate_content([
    video,
    "Опиши всё происходящее: что говорится, что показывается на экране, "
    "объедини в единое понимание содержания включая визуальные фрагменты без речи."
])
```

#### Pipeline для длинного видео (экономный вариант)

```
видео → FFmpeg → аудио → Groq Whisper → транскрипт
                ↓
             кадры каждые 3-5 сек → Claude/GPT-4o → описание визуального ряда
                                          ↓
                    LLM объединяет транскрипт + описания кадров → полный смысл
```

Стоимость ~10 мин видео: Groq Whisper ~$0.02 + кадры в LLM ~$0.05 = **~$0.07**

### АУДИО (главный приоритет)

#### Транскрибация (речь → текст)

**Бесплатные / локальные:**

| Инструмент | Качество | Особенности |
|---|---|---|
| **OpenAI Whisper** (локально) | ★★★★★ | Лучшее open-source, офлайн, все языки |
| **faster-whisper** | ★★★★★ | В 4x быстрее Whisper, Python |
| **Whisper.cpp** | ★★★★★ | C++ порт, работает на слабом CPU |

**Платные (дёшево и быстро):**

| Сервис | Цена | Особенности |
|---|---|---|
| **Groq Whisper Large v3** | $0.111/час | Самый быстрый, ~реалтайм |
| **Deepgram Nova-3** | $0.0043/мин | Стриминг, спикеры, пунктуация |
| **AssemblyAI** | $0.65/час | Хороший русский язык |
| **OpenAI Whisper API** | $0.006/мин | Официальный, дороже Groq |

> **Рекомендация:** Groq Whisper. 1 час аудио = $0.07. Скорость — секунды на длинный файл.

#### Извлечение смысла из аудио (не только транскрипт)

После транскрипта — LLM для:
- Резюме / ключевые тезисы
- Структурирование по темам
- Выделение вопросов и ответов
- Анализ тональности / эмоций

#### Источники аудио

- Подкасты: RSS-фиды (XML) → прямые ссылки на mp3
- Голосовые сообщения Telegram, WhatsApp
- Записи звонков, вебинаров
- Аудиокниги, лекции

## Архитектура: Агент-парсер + Агент-создатель + Ферма

```
┌──────────────────────────────────────────────────────────────────┐
│                     ORCHESTRATOR (Ферма)                         │
│  принимает задачу → решает какие агенты и инструменты поднять   │
└──────────┬──────────────────────────────────────┬───────────────┘
           │                                       │
┌──────────▼──────────────┐           ┌────────────▼──────────────┐
│    PARSER AGENT          │           │    CREATOR AGENT          │
│                          │           │                           │
│  Видео:                  │           │  Текст:                   │
│   - yt-dlp               │           │   - Claude / GPT          │
│   - Gemini Vision        │           │   - промпт-шаблоны        │
│   - FFmpeg               │  ──────►  │                           │
│  Аудио:                  │           │  Изображения:             │
│   - Groq Whisper         │           │   - Midjourney / DALL-E   │
│   - faster-whisper       │           │   - Stable Diffusion      │
│  Текст:                  │           │                           │
│   - Firecrawl            │           │  Видео:                   │
│   - Playwright           │           │   - Runway / Kling        │
│   - Jina Reader          │           │                           │
│  Документы:              │           │  Голос:                   │
│   - PyMuPDF              │           │   - ElevenLabs            │
│   - pdfplumber           │           │   - Resemble AI           │
│  Изображения:            │           │                           │
│   - OCR                  │           │  Публикация:              │
│   - LLM Vision           │           │   - Buffer / n8n          │
│  Соцсети:                │           │   - Telegram Bot          │
│   - Apify                │           │   - Instagram API         │
└──────────────────────────┘           └───────────────────────────┘
```

### Почему разделение правильное

- Парсер накапливает кэш разобранного контента — не разбирать одно видео дважды
- Создатель работает с чистыми структурированными данными, не с сырым контентом
- Оркестратор масштабируется: добавить SEO-агента или аналитика без переписывания
- Разные модели для разных задач: дешёвый Gemini Flash для разбора, мощный Claude для создания

### Технологии оркестрации
