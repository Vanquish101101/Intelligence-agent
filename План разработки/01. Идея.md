# 01. Идея — Агент онлайн-разведчик

## Суть идеи

Создать AI-агента («Разведчик»), который автономно мониторит интернет и социальные сети, собирает трендовую и актуальную информацию, затем формирует отчёт и аналитику для пользователя.

Агент работает **по расписанию (1 раз в день)** или **по запросу пользователя** — всегда в курсе трендов в выбранных сферах.

---

## Режим работы

| Режим | Описание |
|---|---|
| Автоматический | Запуск 1 раз в сутки без участия пользователя |
| Ручной | Запуск по запросу пользователя в любое время |

### Глубина анализа

| Уровень | Модель | Инструменты | Время |
|---|---|---|---|
| `quick` | claude-haiku-4-5 | Perplexity sonar, краткий отчёт | 15–30 сек |
| `standard` | claude-haiku-4-5 | Все инструменты, стандартный объём | 60–90 сек |
| `deep` | claude-sonnet-4-6 | Perplexity sonar-pro + расширенный сбор | 2–5 мин |

**Правило:** все запросы на анализ и поиск выполняются в режиме `standard` по умолчанию. При выборе `deep` включается deepresearch-режим с максимальной детализацией.

## Задачи агента

1. **Маркетинговая разведка** — поиск актуальной информации для проведения маркетинговых кампаний по продукту или услуге.
2. **Анализ трендов** — подбор похожего трендового контента как основы для создания собственного.
3. **Генерация контента** *(на основе найденного)* — посты, фото, видео, Reels при помощи специализированных сервисов.
4. **OSINT-разведка** — поиск по открытым источникам: никнейм, домен, персона, компания, email, телефон, IP. Использует Perplexity sonar-pro + Firecrawl. Команда `/osint [тип] цель`.
5. **Учёт затрат** — агент анализирует расходы на API и выводит таблицу трат после каждого запроса. Команда `/costs`.

> Список задач может дополняться и уточняться в ходе разработки.

## Алгоритм работы (концепция)

```
Пользователь открывает бот (/start)
        ↓
  Выбор режима работы (inline-кнопки):
  ┌───────────────────────────────────────────┐
  │  🔍 Получить информацию                   │
  │     → Агенты 1 + 2 + 3                    │
  │                                           │
  │  🎬 Создать контент                       │
  │     → Агенты 1 + 2 + 3 + 4               │
  │       (Агент 4 в разработке — скоро)      │
  └───────────────────────────────────────────┘
        ↓ режим «Получить информацию»
  Запрос (пользователь / расписание)
        ↓
  Оркестратор
  - Понимает задачу
  - Выбирает ресурсы (по качеству и стоимости)
  - Управляет взаимозаменяемостью ресурсов
        ↓
  Агент-разведчик (Scout)
  - Параллельный сбор данных (Promise.allSettled):
    • Perplexity — факты и тренды
    • Apify YouTube — метаданные видео
    • Firecrawl — текстовые страницы
        ↓
  Двойной вывод:
  ┌─────────────────────────────────────────┐
  │  1. Telegram-текст → пользователю       │
  │     (LLM формирует читаемый отчёт)      │
  │                                         │
  │  2. Структурированный JSON →            │
  │     Supabase `search_results`           │
  │     (сырые данные для Агента 3)         │
  └─────────────────────────────────────────┘
        ↓
  Отправка пользователю
```

Режим сохраняется через `/mode` и хранится в пользовательских настройках (Supabase `user_settings`). Переключить можно в любой момент.

**Ключевые принципы оркестратора:**
- Понимает задачу и процессы её выполнения
- Выбирает оптимальные ресурсы по соотношению качество/стоимость
- При недоступности ресурса — автоматически переключается на альтернативный
- Управляет всеми агентами, плагинами и скиллами

## Место в цепочке из 4 агентов

Marketing agency Project строится как **цепочка из 4 специализированных агентов**. Каждый — отдельный проект в своей папке:

| № | Агент | Проект | Роль |
|---|---|---|---|
| 1 | **Разведчик** | `Intelligence agent` *(этот проект)* | Поиск источников и легкодоступной информации |
| 2 | **Глубокий парсер** | `Deep parsing agent` | Парсинг видео, аудио, документов, сложных сайтов |
| 3 | **Анализатор** | `Information analysis agent` | Синтез смыслов, логика, понимание данных |
| 4 | **Создатель контента** | `Content creation agent` | Генерация постов, видео, Reels |

```
Агент 1 (Разведчик — этот проект)
        ↓ находит источники, передаёт сложный контент
Агент 2 (Глубокий парсер)
        ↓ отдаёт разобранный контент
Агент 3 (Анализатор)
        ↓
Агент 4 (Создатель контента)
        ↓
  Результат → пользователю в Telegram
```

**Роль Агента 1 (этого проекта) уточнена:** Агент 1 занимается **только поиском и нахождением источников**. Всё, что требует глубокого парсинга (транскрибация видео, сложный скрапинг, разбор документов) — сразу передаётся Агенту 2, без попыток Агента 1 делать это самостоятельно.

### Что Агент 1 делает сам:
- Поиск через Perplexity (факты, тренды, актуальность)
- Нахождение источников и ссылок (YouTube, соц. сети, статьи)
- Получение готовых субтитров YouTube (без скачивания видео)
- Быстрый текстовый поиск по открытым ресурсам
- OSINT по открытым источникам

### Что Агент 1 передаёт Агенту 2:
- Видео и аудио (транскрибация, разбор визуала)
- Сложные страницы, требующие глубокого парсинга
- PDF и документы
- Изображения, требующие OCR или vision-анализа

### Как Агент 1 передаёт данные Агенту 3:
Агент 1 сохраняет структурированный JSON в таблицу `intelligence_agent.search_results` (Supabase) после каждого поиска. Агент 3 читает данные оттуда напрямую — без разбора Telegram-текста. Поле `result.raw` содержит сырые данные всех источников; поле `confidence` показывает качество данных.

### Общая инфраструктура (shared):
- **Supabase** — проект `Marketing agency`, отдельные схемы для каждого агента; таблица `intelligence_agent.search_results` — точка передачи данных Агенту 3
- **Redis** — общий Docker-контейнер, сеть `marketing-agency-net`
- Файл деплоя: `Marketing agency Project/Инфраструктура (Docker)/docker-compose.yml`

### Связь с Marketing agency:
Агент 1 также является **вспомогательным модулем** основного проекта **Marketing agency** и выполняет задачи для **Контент-завода**. Интеграция через **MCP-протокол**.

```
Marketing agency (главный проект)
        ↓ задача
  Главный оркестратор
        ↓
  Агент 1 (поиск) → Агент 2 (парсинг) → Агент 3 (анализ) → Агент 4 (контент)
        ↓ отчёт
  Пользователь / Контент-завод
```
